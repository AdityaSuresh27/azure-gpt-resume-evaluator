# Resume AI Evaluator using Azure OpenAI

This project evaluates resumes against job descriptions using OpenAI's GPT model via Azure OpenAI Service. It provides suggestions on how well a candidate's resume fits a specific role, highlighting strengths and areas for improvement.

## 💡 Features

- Upload your resume (in `.docx`, `.pdf` format)
- Input a job description
- Get feedback based on language model analysis

## 🧰 Tech Stack

- Python
- Azure OpenAI (`gpt-35-turbo` or similar)
- `openai` Python SDK
- `docx2txt` for parsing resumes
- `streamlit` for front end
